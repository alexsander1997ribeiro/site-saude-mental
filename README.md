# Mente Saudável — Saúde Mental e Bem-Estar

Projeto educativo sobre saúde mental e bem-estar, desenvolvido como site multipáginas.

## Páginas
- `index.html` — página inicial e apresentação do tema.
- `sobre.html` — informações sobre o projeto e saúde mental.
- `galeria.html` — galeria de cards com conteúdos e dicas.
- `dados.html` — dados apresentados em tabela e perguntas frequentes.
- `contato.html` — página com formulário de contato.

## Tecnologias
- HTML5.
- CSS.
- Bootstrap 5.3.3.
- JavaScript do Bootstrap para os componentes interativos.

## Como visualizar
1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Utilize o menu para navegar entre as páginas.

A conexão com a internet pode ser necessária para carregar os arquivos do Bootstrap caso estejam referenciados por CDN.

## Objetivo acadêmico
Praticar a criação de páginas HTML interligadas, organização de conteúdo, layout responsivo e utilização de componentes do Bootstrap.
